# Publishing

## Validate the upload contract

`manifest.json` declares the document-tree roots included in the Policy Engine bundle. Each non-test Rego package must equal a root or be nested below one. Test modules remain local and are excluded from the upload archive.

Before publishing:

1. confirm the intended package and query paths with the consuming application;
2. run `transcend policy lint <policy-directory> --noInteractive`;
3. review the generated bundle name, version, description, and target Transcend environment;
4. keep API keys in the environment or the repository's approved secret store.

The publish path validates strict Rego compatibility and bundle compilation before creating the upload tarball.

## Publish deliberately

Run `transcend policy publish --help` for the current required flags and authentication scopes. Publishing creates or updates remote Policy Engine bundle resources, so keep it out of pull-request validation and require the repository's normal deployment approval.

Do not add publishing, Transcend API credentials, or environment activation to the validation-only workflow generated by `policy init`. Treat those as separate deployment decisions.

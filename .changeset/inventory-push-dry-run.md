Preview changes before you apply them. `transcend inventory push --dryRun` lists what a push would create, update, or delete, including changes you did not write in the file, and changes nothing. `transcend inventory pull --dryRun` shows how the file would change without writing it. Add `--json` to push for machine-readable output.
